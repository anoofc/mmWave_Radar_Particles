# Coordinate and detection calibration

1. Mount the assembled kit securely and mark its origin on the floor. Record mounting height, pitch and orientation. The dashboard shows native sensor X/Y in metres; it does not apply an assumed rotation, scale correction or height projection.
2. At several measured positions (for example, 1, 2 and 3 m ahead and ±1 m lateral), record raw X/Y and confirm sign/orientation. Keep away from reflective metal, mirrors and moving curtains. Consult the vendor guide for mounting limitations.
3. Use **Invert X/Y** only for display and normalized screen mapping. It does not alter raw telemetry or exported packets. Both axes span ± the selected view range. Range is a view scale, not a command that changes sensor detection coverage.
4. The 3 m, ±60° dashed sector is a **visual reference** for the chosen working range, not a claim that the sensor detects uniformly within that sector. The inner 1.5 m ring helps identify the near-field breathing/heartbeat operating region described by Seeed. Validate useful detection coverage physically before defining installation boundaries.
5. Start with α=1 and dead zone=0 to inspect raw noise. Reduce α gradually (default .3) and add a small dead zone (default .025 m). Smoothing uses new target reports only, not repeated USB copies. α is per report, so changing report frequency changes the effective response time.
6. Check presence and target availability independently during stationary and moving tests. Seeed notes different behavior in the close breathing/heartbeat region. Never infer absence from unavailable coordinates.
7. Measure actual report gaps. Choose target hold and stale thresholds to tolerate normal cadence while suppressing old motion. The default hold is 700 ms, stale limit 2200 ms; firmware invalidates individual reports after 2500 ms. Very low report rates may require calibration rather than more smoothing.
8. Verify cluster continuity with multiple people. Cluster IDs are sensor cluster indices, not guaranteed permanent person identities. Duplicate diagnostics flag same-cluster or nearly coincident (<.08 m) targets as candidates; nearby genuine people can also trigger them. Raw targets remain visible and recorded.

The maximum and default view range is ±3 m, with 1 m and 2 m zoom options. The four rings are at one-quarter, one-half, three-quarters and the full selected view range: by default 0.75, 1.5, 2.25 and 3 m; at ±2 m they are 0.5, 1, 1.5 and 2 m. Ring labels update with the view. The normalized interaction mapping uses the same selected range. This sets the dashboard working scale, not the radar module's physical detection limit, and does not discard raw measurements. There is no software clamp at the first ring. Each target label includes `r = sqrt(x²+y²)` from its filtered native coordinates; this is planar coordinate distance, not the separate optional sensor distance field.

If a target remains inside the first ring while you walk well beyond its measured radius, compare raw and filtered X/Y with smoothing α=1 and dead zone=0 at known physical positions. Record at approximately 1, 2 and 3 m with one person in view and the sensor mounted securely facing the walking path. If raw coordinates plateau too, changing the plot range only zooms the display and cannot correct sensor measurements. Sensor mounting, reflectors, selected target and radar-module firmware must then be checked against the physical positions.

Position-derived interaction velocity measures changes in filtered native X/Y per elapsed measurement time. It resets on cluster switching, long gaps or source changes. The Doppler-derived value shown in the target table uses the vendor's documented conversion and must be validated separately before physical speed analysis. Optional distance is deliberately not labeled metres until its unit is independently verified.
